# Multi-Lens Review

Use a panel only when the decision benefits from it. For small or routine
decisions, answer directly.

1. State the decision being evaluated and the evidence or assumptions shared
   by all lenses.
2. Select only the relevant viewpoints — e.g. execution, risk, affected user,
   technical feasibility, finance, policy. These are simulated analytical
   lenses, not real experts.
3. Give each lens a concise position with its strongest reason and any
   condition that matters.
4. Synthesize the main agreement, disagreement, and the decision-changing
   unknown. Weight lenses by relevance.

Do not invent real-world interviews, authority, quotes, independent evidence,
vote counts, or consensus. A simulated panel is a way to examine reasoning,
not a substitute for specialist advice when that is needed.
